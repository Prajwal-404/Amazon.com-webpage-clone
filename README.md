# Amazon.com CSS Clone

A beginner-friendly **Amazon.com webpage clone** built using **HTML and CSS**.
This project focuses on recreating the layout and styling of an e-commerce website while practicing fundamental frontend development concepts.

## 🚀 Features

* Amazon-style navigation bar
* Search bar
* Account and cart sections
* Navigation panel
* Hero/banner section
* Product/category sections
* Amazon-style footer
* Responsive layout basics
* Styled links, buttons, and sections using CSS

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Git & GitHub**

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Prajwal-404/Amazon.com-webpage-clone.git
```

### 2. Open the project

```bash
cd Amazon.com_CSS-clone
```

### 3. Start a local server

```bash
python -m http.server 8000
```

### 4. Open in your browser

Go to:

```text
http://localhost:8000
```

### 5. Stop the server

When you're finished, press:

```text
Ctrl + C
```
